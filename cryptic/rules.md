# Cryptic Clue Rules — Learned from Setting Sessions with Anant

These rules are built up iteratively. They override general knowledge about cryptics
where they conflict — this is Anant's house style.

---

## Surface reading

- The surface must read as natural, misleading English. It is the most important thing.
- Punctuation is purely surface dressing — never structural. No colons, dashes or
  question marks to signal the boundary between wordplay and definition.
- No ? at the end unless it is genuinely a cryptic definition (F3). Do not add ?
  just because the clue is oblique or clever.

## Definitions

- The definition must be specific enough that a solver can confirm the answer
  with confidence. "More nowadays" is too vague for GAS PRICES; "at the pump" works.
- But do not make the definition so on-the-nose that it gives the game away immediately.
  "at the pump" is borderline; prefer something that requires a moment's thought.
- "to do" is a defensible loose definition for TASKS (things you have to do).
- Definition by example (F4): "Radon, say" = GAS is elegant. "Say" is the indicator.

## Anagrams

- Avoid anagramming answers made of mostly common letters (A, E, S, I, R, T, N, O…).
  Too many possible fodder phrases — the clue feels loose and unsatisfying.
- Prefer anagrams where the answer contains rare letters (K, V, W, X, J, Q, Z, double
  unusual letters) — these tightly constrain the fodder and feel more elegant.
- TERRACE works well: anagram of CATERER (two R's, two E's constrain it nicely).
- The anagram indicator should feel natural in the surface — "stumbles" works both
  as indicator and as vivid image of a caterer tripping on a patio.

## Charades

- Each component of a charade can use any sub-mechanism: synonym, abbreviation,
  definition by example, initial letter, reversal, etc.
- T = time is a standard abbreviation. ASKS = makes requests. T + ASKS = TASKS.
- The surface should make the components invisible — "Time to make requests to do"
  reads as a natural reminder, not as a recipe for T + ASKS.

## Double definitions

- Both definitions must be genuinely different senses of the answer.
- STRAITS: "tight spots" (dire circumstances) + "between lands" (waterways). Clean.
- No indicator needed or wanted.

## Anagram fodder — multi-word is fine

- Anagram fodder can span multiple words and components: "I + STRIP + S(omewhat)" = ISTRIPS → SPIRITS.
- Initial-letter extraction ("some initially" → S) can contribute a letter to anagram fodder.
- The fodder phrase does NOT need to be a clean single word or idiom — "I strip somewhat" works fine.
- A word's first letter (abbrev indicator: "initially", "first", "opening") is a standard building block.

## Standard abbreviation components (from clue bank)

- ME or I = the writer (convention: the setter/solver = first person)
- O = love (tennis zero), or old
- LTD = limited
- LE / LA / LES = the (French)
- URE, FAL, EXE = British rivers usable as components
- R = runs (cricket); S = son (cricket)
- Standard compass: N, S, E, W

## Container clues

- One word inserted inside another: MA inside CRETE = C-R-E-MA-TE = CREMATE
- Inner indicator: "in", "inside", "entering", "within"
- Outer indicator: "holds", "around", "swallowing", "embracing"

## Deletion via subtraction

- "runs out of BARN" = remove R → BAN
- "Tallinn resident expels son" = ESTONIAN – S = ETONIAN
- "shelled" = remove outer letters (shell of crab = just the exterior stripped away)
- "nearly all" can mean remove AL from a word

## Surface excellence — what to aim for

- Best anagram clues: the indicator word works as vivid surface imagery too.
  "Tangled roots and trunk" → anagram of ROOTS = TORSO: "tangled" describes roots visually
  AND is the indicator; "roots and trunk" misleads toward trees but defines TORSO.
- "Seasoning minced, not ground" → MINCED NOT anagram = CONDIMENT: "minced" is both
  the indicator AND part of the fodder — semi-&lit elegance.
- Aim for surfaces where indicator + fodder = a natural scene the solver misreads entirely.

## Self-check protocol — run before presenting any clue

Before proposing a clue, verify all of the following explicitly:

1. **Letter inventory**: List every letter contributed by each wordplay component.
   Confirm they exactly match the answer's letters (same count, same letters).
   Example: I(1) + STRIP(5) + S(1) = I,S,T,R,I,P,S → sorted A→Z: I,I,P,R,S,S,T
   SPIRITS = S,P,I,R,I,T,S → sorted: I,I,P,R,S,S,T ✓

2. **Component count**: Total letter count of components = letter count of answer.
   No surplus letters, no deficit.

3. **Definition position**: Definition must be at the very start or very end of the clue.
   Never in the middle. Check it is there and that it is specific enough to confirm.

4. **Indicator legitimacy**: Is the indicator a real, standard cryptic indicator for this
   mechanism? If unusual (like "early" for first-letter), flag it as non-standard.

5. **Every word accounted for**: Each word in the clue is either:
   - Part of the wordplay (fodder, component, abbreviation source), or
   - The definition, or
   - A valid linking word ("for", "in", "and", "to") or surface glue.
   No word should be unaccounted for.

6. **Answer not in clue**: The answer word must not appear verbatim in the clue surface.

7. **Surface reads naturally**: Read the clue as plain English. Does it make sense as a
   sentence or phrase, even if the meaning is odd or misleading?

## Bust-check discipline

- Run bust checks quickly before proposing a mechanism. Do not deliberate — if it
  does not work in seconds, move on.
- Reversal: bust if reversed answer is gibberish.
- Anagram: bust if answer is all common letters.
- Hidden: bust if answer is long (7+ letters) unless a very natural phrase presents itself.
- Palindrome: bust unless answer actually is one.
- Homophone: bust if answer sounds like nothing else.
- Roll again immediately rather than forcing a weak mechanism.

## Key synonyms worth knowing

- test = TRIAL (vital for container/charade clues — "easy six in a test" = VI in TRIAL)
- six = VI (Roman numeral)
- Articles ("a", "an", "the") before noun components are acceptable surface glue
